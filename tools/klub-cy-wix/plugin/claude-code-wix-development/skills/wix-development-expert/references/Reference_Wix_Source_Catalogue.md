## Citation Policy

Every factual or behavioral claim should resolve to an official Wix documentation URL or Wix-owned repository when possible. The local full-document snapshot is an acquisition artifact; public-facing citations should link to the canonical Wix page or repository. For a method invocation, the current live method schema supersedes examples and this corpus.

## Known Boundaries

The corpus does not claim that an API can reproduce every Wix Studio editor action. Neither lightweight skill includes raw source clones, user credentials, a live destination site, or approved Wix writes. The corpus does not fix future prices, AI credit costs, quotas, package versions, or MCP tool contracts beyond the research date.
